JustTheSpec runs in your browser, nothing uploaded

Some vendors only document their API as a PDF. Drop it here and get an OpenAPI spec: import it into Postman, Insomnia or Bruno, generate a client, or hand it to your AI assistant. Drop the next version to see what changed before it breaks production.

  • Drop the PDFYour browser reads it. There is no server behind this page, so nothing is uploaded or kept.
  • Get the specOpenAPI 3.0, with the source page of every endpoint. No account, no key, no AI.
  • Use itDownload it, import it into your API tool, or compare it with the previous PDF.

    Optional: refine with your own AI model

    Sends each endpoint's source pages (text only, never the whole PDF) to a model you choose, which fills in summaries and fields the rule-based parser missed. The key is kept in this tab's memory and forgotten when you close it.

    Use the result

    Postman, Insomnia, Bruno

    Download the spec, then: Postman Import → drop the file. Insomnia Create → Import. Bruno Import collection → OpenAPI V3. Every endpoint becomes a ready-to-send request.

    Claude, Cursor or any MCP client

    Let your assistant convert, diff and validate PDFs itself, using its own model for the hard parts. Add this to your client's MCP config:

    {
  "mcpServers": {
    "justthespec": { "command": "uvx", "args": ["--from", "git+https://github.com/12burb/justthespec", "justthespec", "mcp"] }
  }
}

    Command line and CI

    Same parser, plus OCR for screenshots, a daily check of the vendor's PDF URL that fails when it changes, and a live check against the vendor's sandbox.

    pip install git+https://github.com/12burb/justthespec
justthespec extract vendor-api.pdf -o vendor-api.yaml
justthespec diff vendor-api.yaml https://vendor.example.com/api-docs.pdf --fail-on-change

    Code generators

    Feed the spec to OpenAPI Generator, openapi-typescript or similar to get a typed client. Check x-source-pages against the PDF for anything that looks off.

    Did the vendor change something?

    Drop the previous version of the PDF (or a spec you downloaded here earlier) to see added, removed and changed endpoints, with breaking changes flagged.
